
# IT Development and Operations CDS 212

Dieses Projekt dies als Semesterarbeit für das Fach CDS212 IT Development and Operations und dient der Lehrperson für die Evaluation der Arbeit.

## Voraussetzungen
- Python ≥ 3.11

## Installation
```
git clone git@github.com:Ilaj12Luechinger/DevOps.git
cd DevOps
python -m venv .DevOps && .DevOps/bin/activate
pip install -r requirements.txt
```
